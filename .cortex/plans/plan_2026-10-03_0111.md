## Plan: One-Click Infrastructure Setup Wizard for SiS

### Findings
- The SiS app runs inside Snowflake — no local filesystem access
- Synthetic data must be generated via pure SQL (`GENERATOR`, `UNIFORM`, `DATEADD`)
- The OEM PDF is in `data/` in the repo — CI/CD can upload it via `snow stage copy`
- The semantic model YAML is also in `semantic_models/` — same approach
- `snow stage copy` supports local-to-stage uploads in CI/CD

### Implementation Steps

**1. Create `streamlit/pages/0_Setup.py`** — One-click setup wizard with progress indicators:

| Phase | What it does | SQL equivalent |
|-------|-------------|----------------|
| 1 | Create tables, dynamic table, stages | `01-infrastructure.sql` |
| 2 | Generate ~50K OT rows + ~200 IT batch rows via SQL `INSERT...SELECT` with `GENERATOR()` | Replaces `data_generator.py` + CSV upload |
| 3 | Refresh dynamic table | `ALTER DYNAMIC TABLE ... REFRESH` |
| 4 | Insert OEM thresholds (4 rows) | `INSERT INTO OEM_EQUIPMENT_THRESHOLDS` |
| 5 | Parse OEM PDF from stage + chunk | `SNOWFLAKE.CORTEX.PARSE_DOCUMENT` + INSERT |
| 6 | Create Cortex Search Service | `04-cortex-search.sql` |
| 7 | Create views + train ML models + predict | `03-analytics.sql` |
| 8 | Create Slack webhook notification (optional) | `05-sis-external-access.sql` |

Each phase: checks if already done (idempotent), shows status emoji, wraps in try/except with user-friendly errors. A single "Deploy Infrastructure" button triggers all phases sequentially with a progress bar.

**2. Update `.github/workflows/deploy-sis.yml`** — Add steps after infrastructure SQL:
```yaml
- name: Upload OEM PDF to stage
  run: snow sql -q "PUT 'file://data/OEM_Maintenance_and_Operations_Manual.pdf' @OEE_COMMAND_CENTER.FACTORY_FLOOR.OEM_MANUALS_STAGE AUTO_COMPRESS=FALSE OVERWRITE=TRUE" -x

- name: Upload semantic model to stage
  run: snow sql -q "PUT 'file://semantic_models/factory_health_ontology.yaml' @OEE_COMMAND_CENTER.FACTORY_FLOOR.SEMANTIC_MODELS_STAGE AUTO_COMPRESS=FALSE OVERWRITE=TRUE" -x
```

**3. Update `streamlit/app.py`** — Add detection: if tables are empty/missing, show a banner directing user to the Setup page.

### Synthetic Data Generation Strategy (pure SQL)
- 5 equipment lines, 3 SKUs, 7 days
- OT: `INSERT INTO RAW_OT_TELEMETRY SELECT ... FROM TABLE(GENERATOR(ROWCOUNT => 50400))` with `DATEADD`, `UNIFORM`, realistic temp/vibration curves
- IT: `INSERT INTO RAW_IT_BATCHES SELECT ... FROM TABLE(GENERATOR(ROWCOUNT => 210))` with 2-4h batch windows
